# User Session Tracking System

A Python application with a graphical user interface (GUI) to manage user registration, login/logout, session tracking, and viewing logs. Built using Tkinter and SQLite for data storage.

## Features
- User registration with unique usernames
- User login and authentication
- Real-time session management (prevent multiple logins)
- Log out functionality
- View session logs with timestamps
- Simple and intuitive GUI
